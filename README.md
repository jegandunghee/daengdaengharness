[개발:  기능]
*장바구니 상태 관리 로직 구현 
  * 전역 배열 기반 cartProduct.js로 장바구니 데이터 관리
  * 상세 페이지(Info.js)에서 전달된 상품 정보를 장바구니에 저장 및 동기화 처리
*동일상품, 동일 옵션 => 병합 처리
  *productId + size + color 조합으로 cartKey생성 
  *같은 상품, 옵션이 존재할 경우 수량 증가 방식으로 병합 처리
*개별/전체 선택 기능
  *상품별 체크박스 토글 기능 구현
  *전체 선택 / 전체 선택 해제 기능 구현
  *선택된 상품 기준으로 주문하기 및 총합 계산 처리 
*수량 증감 로직 구현
  * 최소1개 제한
  * 수량 변동 시 즉시 장바구니 상태 및 총 금액 반영
*옵션 변경 기능 
  * 옵션 변경 시 새로운 cartKey 생성 
  * 옵션 충돌로 인한 중복 아이템 방지 로직 구현 
    [ cartProduct.js ]
      cartJoinKey() : 같은 상품 + 같은 옵션을 판벼라는 장바구니 페이지 내에서 생성되는 고유Key 생성 함수 
      cartOption() : 옵션 변경 시 Key 재생성 + 중복이면 합치는 로직 구현 
*상품 삭제 및 주문하기 처리 
  *체크된 상품만 선택 삭제 가능
  *주문하기 버튼클릭 시 선택된 상품만 장바구니에서 제거 
  *주문 완료 팝업 표시 
*총 주문 금액 계산 
  *체크된 상품 기준으로 수량 x 가격 누적 계산 
  * 실시간 금액 반영
*스크롤 기반 UI처리
  *스크롤 위치에 따라 상단 장바구니 바 fixed 처리 
  * 타이틀('장바구니') 표시/숨김 처리
